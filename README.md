## 🚀 How to Run the Website Locally

You do **not** need any backend server, Node.js runtime, or build tools to view or run this website.

### Option 1: Double-Click (Simplest)
1. Extract the downloaded `manasa-kulal-portfolio.zip` file.
2. Locate `index.html` inside the unzipped folder.
3. Double-click `index.html` to open it in Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, or any modern web browser.

### Option 2: Live Server in VS Code
1. Open the unzipped folder in Visual Studio Code.
2. If you have the **Live Server** extension installed, right-click `index.html` and click **"Open with Live Server"**.
3. The portfolio will automatically open at `http://127.0.0.1:5500/`.

## 🌐 How to Publish for Free using GitHub Pages

Publishing on GitHub Pages will give you a public URL (e.g., `https://<your-username>.github.io/<repo-name>/`) that you can add to your LinkedIn profile, internship applications, and resume.

### Step-by-Step Instructions:

1. **Log in to GitHub**:
   - Go to [github.com](https://github.com/) and log in (or create a free account).

2. **Create a New Repository**:
   - Click the **`+`** icon in the top right corner and select **New repository**.
   - Set the **Repository name** (e.g., `portfolio` or `manasa-kulal-portfolio`).
   - Keep the repository **Public**.
   - Leave "Initialize with a README" unchecked (since we already have a README).
   - Click **Create repository**.

3. **Upload the Portfolio Files**:
   - On the repository page, click **"uploading an existing file"** (or use Git CLI if preferred).
   - Drag and drop the following files and folders:
     - `index.html`
     - `style.css`
     - `script.js`
     - `README.md`
     - `assets/` folder (with `Manasa_Kulal_Resume.pdf`, `resume.html`, and `favicon.svg`)
   - Type a commit message (e.g., `Initial portfolio launch`) and click **Commit changes**.

4. **Enable GitHub Pages**:
   - In your repository, click the **Settings** tab.
   - In the left sidebar, click **Pages** (under "Code and automation").
   - Under **Build and deployment**:
     - Source: Select **Deploy from a branch**.
     - Branch: Select **`main`** (or `master`) and folder **`/ (root)`**.
     - Click **Save**.

5. **Access Your Live Website**:
   - Wait 1 to 2 minutes for GitHub to build your site.
   - Refresh the Pages tab. You will see a banner:
     > *"Your site is live at `https://<username>.github.io/<repo-name>/`"*
   - Click the link to view your live portfolio online!
