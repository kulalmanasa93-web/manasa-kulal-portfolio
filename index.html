NLP & Conversational AI

General FAQ Chatbot

TF-IDF & Cosine Similarity Query Matcher with Gradio UI

Project Summary

An automated conversational agent developed using Python. It bridges natural language user inquiries with a knowledge base by preprocessing text, vectorizing words using TF-IDF (Term Frequency-Inverse Document Frequency), and scoring cosine similarity to retrieve accurate answers.

Key Features & Algorithmic Pipeline

  • Text Preprocessing: Tokenization, lowercasing, punctuation cleaning, and stop-word removal.
  • TF-IDF Vectorization: Converts question-answer pairs and incoming queries into sparse numerical vector space.
  • Cosine Similarity Ranking: Computes angular distance between user query vector and knowledge database questions to retrieve highest-scoring answer.
  • Gradio Web Interface: Provides an intuitive, responsive chat interface for real-time interaction.

Technologies Used

Python TF-IDF Cosine Similarity Text Preprocessing Gradio UI

Blood Management System

Web-based donor management platform using PHP & MySQL

Project Summary

A full-stack web application engineered to manage blood donation records, donor availability, and emergency recipient queries. It bridges donors and hospitals by maintaining synchronized inventory records in a MySQL relational database running on XAMPP.

Key Features & Architecture

  • Donor Registration & Management: Form for donor onboarding with blood type, contact details, and location tracking.
  • Blood Inventory Tracking: Live status of blood units classified by group (A+, B+, O+, AB+, etc.).
  • Relational MySQL Schema: Normalized database tables ensuring data integrity and fast queries via SQL.
  • Interactive UI: Responsive frontend built with HTML, CSS, and JavaScript for seamless navigation.
